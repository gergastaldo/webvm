`SymbolsNerdFont.woff2` is the symbols-only [Nerd Fonts](https://www.nerdfonts.com/) font (taken from the `nerdfonts-web` npm package, which packages the upstream "Symbols-2048-em Nerd Font Complete"). It is used as a fallback glyph source in the WebVM terminal, so TUIs like yazi can show their icons. See the [Nerd Fonts repository](https://github.com/ryanoasis/nerd-fonts) for licensing details.
